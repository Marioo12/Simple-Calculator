## Features
- Two number inputs
- Operator dropdown: addition, subtraction, multiplication, and division
- "Hitung" button to calculate
- Popup that shows the result or an error message
- Math-themed background with a green card layout

## Files
- `index.html` – Calculator page
- `style.css` – Styling and layout
- `JavaScript.js` – Calculator logic
- `Math.jpg` – Background image
